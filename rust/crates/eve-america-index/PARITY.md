## Differences
- A `creditsCost` of JSON `true` reaches this crate through `eve_web::firecrawl::run_tool` as the number 1 (eve-web's `Ran` keeps it that way), so the default runner meters 1 credit where Python's `_finite_number(True)` would meter it unpriced. An injected runner returning `true` is metered unpriced, as in Python.
- Wrong-typed arguments Python rejects at run time (see Tests) are rejected by the Rust types at compile time.
