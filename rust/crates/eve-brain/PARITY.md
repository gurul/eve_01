## Boundaries
What this crate leaves to the operating system or the network, unchanged from Python; the tests reach each one through a lent seam or not at all.

- `git rev-parse --short HEAD` (self_context's `running_commit`): a child process; the tests lend the commit (`Lent.commit`).
- `osascript` (share.py's Finder and Messages scripts): a child process with a timeout; the tests lend the runner.
- `cloudflared tunnel --url` (miniapp's QuickTunnel) and `taskkill` on Windows: a child process; the tests lend the binary path or never start it.
- `screencapture -x -t jpg` (the chat's `send_screen`): a child process; the tests lend `screen`.
- The OpenAI Live API (voice_agent's `open_session`): a websocket over tokio-tungstenite; the tests lend a fake connection (`FakeConn`).
- The speaker (voice_agent's `Speaker`): cpal; the tests lend a fake speaker.
- Telegram's Bot API, OpenRouter and OpenAI's Responses API: HTTP through the `Http` transport seam; the tests lend fakes or a MockTransport (tests/more).

## Differences
Each one is a place a Python test or caller would see something other than Python's behaviour, or a seam that replaces a Python monkeypatch.

- Errors a Python function raised into a caller that only logged them are logged here and returned as `Err` or a refusal dict; where Python's message named the exception class, Rust names the Python class it stands for (`RuntimeError`, `ValueError`), and an error of no Python class is named "Exception".
- httpx's per-request INFO log line (which Python's tests muted) is not written: the transport is not httpx.
- `Pending::set_result` returns whether it took the value (Python's `future.set_result` raises InvalidStateError on a second call; every caller here guarded with `done()` first).
- The inlet reads HOME, the web search and the environment from what it is lent (`InletOptions.environ`, HOME inside it, `tt_set_web_search`), never from the process: Python's tests monkeypatched `Path.home`, the environment and `websearch.search`.
- App modules (spotify, firetv, obsbot_panel) are lent through `AppHubs`, or, where Python called `app.mod()`, built in by `seams::app_module` from the real crates.
- Python's tests swapped `TOOL_HANDLERS` entries for spies; Rust dispatches by `match`, so the ported tests read what each handler touched (the agent, the launcher, the screen, the apps, the model, the chat).
- The toolset router's `TIMEOUT_S` is a constant: the test that patched it to 0.05 s lends a router that sleeps past the real budget.
- `TelegramApi::notifier()` (defaulted to None) is how `make_inlet` lends the API's notifier, where Python read an attribute off the API object.
- The long-email test does not patch `_ask_user`: the question reaches the app (it is an app turn) and the owner says no.
- The agent's `ui_evidence` is read off `TaskAgent::status()["ui_evidence"]`; the seam has no attribute of its own for it.
- `test_the_self_context_block_stays_under_budget_with_everything_on` cannot patch `chief.SHIPPED` (a Rust const): it reads the switch with `eve_chief::enabled_shipped(.., false)` and checks the block's EVE_CHIEF=off form in place of the patched auto.
- test_telegram_chief.py's history kept the turns of a chat that closed (`close_and_keep`); the Rust rig keeps the turns just before the poll loop's shutdown closes the chat, the one close these tests see.
- Test hooks (`tt_*`, `#[doc(hidden)]`) stand for the private attributes Python's tests set and read (`inlet._chat_id`, `inlet._tool`, `inlet._app_filed`, ...); nothing outside `tests/` calls them.
- `share.attachment_mail`: a file name holding a literal RFC 2047 encoded word (`=?utf-8?q?x?=.pdf`) is written as given in Subject and Content-Disposition, where Python's header parser decodes it first (Python writes `x.pdf`). A To value that is not a plain dot-atom `local@domain` or `<local@domain>` (a display name, a quoted local part, `a..b`, a comment, a group `a:b@c.d`, a domain literal) is written as given when it fits and otherwise folded, where Python's parser repairs it first (closes a quote, adds a group `;`); Python raises HeaderWriteError for a long non-ASCII `<local@domain>`, which Rust writes. Neither comes from a Contacts address or a handle that passes `is_email`.
- `apps_maker.AppStore.info` returns None (and logs) when `versions/` cannot be read or migrated (mkdir, or the rename of index.prev.html, fails), where Python's `_versions` OSError propagates to `list()`/`save()`.
- `apps_maker.AppStore.requests` returns each request as a map of `str()` values and drops entries that are not dicts, where Python returns meta.json's list as it is; its callers (`edit_prompt`, the chat door) read only `at` and `text`.
- `voice_agent.VoiceSession.PHOTO_TIMEOUT_SECS` is one process-wide value (`voice_agent::PHOTO_TIMEOUT_SECS`), Python's class attribute; Python's tests set it on one session, the Rust photo tests take turns with it under a mutex.
- A hush (the voice run future dropped) skips the awaits Python's cancelled `finally` makes: queued audio is dropped instead of drained, the scene is stopped in the background, and the agent task and idea saves are not awaited.
- `_chief_command` (`go`, `raise`, `tomorrow`) and `_meet_command` (`leave`) read a missing key of the chief's or Meet's result as `None` where Python raises KeyError; neither ever returns such a dict. Where Python logs `type(exc).__name__` for a tool or Codex failure of no Python class, Rust logs the error's message.
- `edit_message` with text that composes to no pieces returns `BotApiError(400, "Bad Request: message text is empty")` where Python's `[0]` raises IndexError.
- `send_photo`'s content type comes from `mime_guess`, not `mimetypes.guess_type`; the two can differ on rare extensions.
- `EVE_TELEGRAM_OWNER` entries past i64, and digits `str.isdigit` takes that are not decimal (Python raises on these in `int()`), are ignored with the warning.
- The Codex folder lister: `InletOptions.codex_folders` (an infallible lister, a test's lambda) or `codex_folders_result` (one that can raise CodexUnavailable); with neither, `accessible_folders` raises for a missing or broken saved-folders file and the owner reads "Could not read saved Codex folders." as in Python.
